# Данные и препроцессинг

В этой папке размещаются модули для:

- загрузки датасета (mock/открытый);
- базовой очистки данных;
- построения preprocessing pipeline (imputer/scaler/encoder).

Все трансформации должны быть воспроизводимыми и пригодными для инференса.

## Что уже реализовано

- `loader.py`:
  - `load_dataset(...)` загружает CSV или создаёт mock-данные;
  - целевая колонка: `default`.
- `preprocessing.py`:
  - `infer_feature_config(...)` автоматически выделяет типы признаков;
  - `build_preprocessor(...)` строит единый preprocessing pipeline.

## Важно

- Любые изменения признаков здесь автоматически влияют на обучение и на будущий инференс.
- Имена и порядок признаков после трансформации сохраняются в артефакты и используются для explainability.
