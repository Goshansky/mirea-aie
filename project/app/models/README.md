# Схемы и модели приложения

В этой папке размещаются:

- pydantic-схемы входных и выходных данных API;
- типы и вспомогательные модели, используемые в сервисах.

Схемы должны быть строгими и содержать валидацию бизнес-ограничений.

Текущие файлы:

- `schemas.py`:
  - `PredictRequest` (валидация входа для `/predict`);
  - `PredictResponse` (ответ API);
  - `HealthResponse` (ответ `/health`).
- `predictor.py`:
  - `LoadedArtifacts` — контейнер загруженных артефактов модели и metadata.
