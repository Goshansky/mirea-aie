# Маршруты API

В этой папке находятся модули маршрутов FastAPI.

Реализованные роуты:

- `health.py` — проверка доступности сервиса (`GET /health`);
- `predict.py` — скоринг заявки (`POST /predict`).

Каждый роут должен быть тонким: без тяжёлой бизнес-логики, только оркестрация сервисов.

В `predict.py` уже добавлены:

- обработка ошибок (`400`, `500`);
- логирование ошибок и исключений;
- зависимость `InferenceService` через `Depends`.
