# Core модуль

Общие компоненты backend-приложения:

- конфигурация (`.env`, пути, пороги решений);
- логирование;
- общие константы и правила принятия решений.

В `core/` не должно быть доменной бизнес-логики инференса.

Сейчас в `core/` реализовано:

- `config.py` — загрузка `Settings` из переменных окружения;
- `logging.py` — инициализация стандартного logging;
- `decision.py` — функция `resolve_decision(...)` для PD-порогов.
