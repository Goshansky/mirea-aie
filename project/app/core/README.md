# Core модуль

Общие компоненты backend-приложения:

- конфигурация (`.env`, пути, пороги решений);
- логирование;
- правила принятия решения и бизнес-ограничения.

Сейчас в `core/` реализовано:

- `config.py` — `Settings` из переменных окружения (пороги PD, штрафы, лимиты);
- `logging.py` — инициализация стандартного logging;
- `decision.py` — `resolve_decision(...)` (APPROVE / REVIEW / REJECT по PD);
- `business_rules.py` — авто-одобрение/отказ и post-ML штрафы к PD (возраст, линии, просрочки и др.).

Тяжёлый инференс модели и SHAP — в `app/services/`.
